# UVic Tour Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development
> (recommended) or superpowers:executing-plans to implement this plan task-by-task.
> Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A stylized, offline-capable 3D campus map that shows one student exactly where
their five Fall-2026 classes are, how long the walk is, and what else on campus matters.

**Architecture:** Static single-page app. MapLibre GL JS is used purely as a geospatial
camera + renderer — we supply **100% of the visual content as our own GeoJSON and render
zero raster tiles**, which means no API key, no attribution box, total art direction, and a
small payload. All campus geometry is fetched once from OpenStreetMap at build time by a
Node script and committed as static JSON. Walking routes are computed in-browser with A*
over a pre-baked graph, so the app needs no network after first load. All schedule logic
lives in pure, unit-tested functions with no map or DOM dependency.

**Tech Stack:** Vite 6 · TypeScript 5 (strict) · MapLibre GL JS 4 · Vitest (unit) ·
Playwright (E2E) · vite-plugin-pwa. No UI framework — a ~40-line reactive store plus
render functions. No backend.

**Spec:** `docs/SPEC.md`

## Global Constraints

- **No API keys, no runtime network calls.** Anything fetched from OSM happens in
  `scripts/build-data.ts` and is committed to `src/data/generated/`. If a task needs a
  network call at runtime, the task is wrong.
- **Gold (`--gold`, `#FFB627`) is reserved exclusively for the student's own class
  buildings.** Never use it for POIs, chrome, or decoration.
- **Every pure module in `src/core/` must have zero imports from `src/map/` or `src/ui/`**
  and must be unit-tested. Enforced by a test in Task 15.
- **All five courses come from `src/data/schedule.ts` only.** No course data may be
  hardcoded anywhere else. That file must stay readable enough to edit by hand.
- **Term dates:** 2026-09-09 → 2026-12-07. Campus timezone `America/Vancouver`.
- **Respect `prefers-reduced-motion`** in every animation. Non-negotiable.
- **Typecheck must pass:** `npm run typecheck` (`tsc --noEmit`) is part of "done" for
  every task.
- Commit after every task with a `feat:`/`test:`/`chore:` prefix.

## Task 2: Bake campus geometry from OpenStreetMap

**Files:**
- Create: `scripts/build-data.ts`
- Create (generated, committed): `src/data/generated/buildings.geojson`,
  `paths.geojson`, `walkgraph.json`, `meta.json`
- Test: `tests/unit/generated-data.test.ts`

**Interfaces:**
- Produces:
  - `buildings.geojson` — `FeatureCollection<Polygon>`, each feature has properties
    `{ id: string, name: string|null, height: number, riseDelay: number }`.
    `height` in metres (authored, see Step 2). `riseDelay` is `0..1`, proportional to
    distance from campus centroid, used by the load animation.
  - `paths.geojson` — `FeatureCollection<LineString>` for ambient path rendering.
  - `walkgraph.json` — `{ nodes: [lat, lon][], adj: [number, number][][] }` where
    `adj[i]` is a list of `[neighborIndex, metres]`.
  - `meta.json` — `{ center: [lon, lat], bbox: [w,s,e,n], generatedAt: string }`.

**Context:** The Overpass query and its results are already verified (2026-09-07):
382 buildings / 959 walkways / 5,779 graph nodes / 98.2% single connected component.
Bbox is `48.4585,-123.3200,48.4700,-123.3020`.

- [ ] **Step 1: Write the fetch + parse script**

Query Overpass with `out geom;` for `way["building"]` and
`way["highway"~"^(footway|path|pedestrian|steps|cycleway|service|living_street|residential|unclassified|tertiary)$"]`
within the bbox. Write raw response to `.cache/osm.json` and reuse it if present, so
re-runs don't re-hit the API.

- [ ] **Step 2: Author building heights**

OSM only has `building:levels` for 13 buildings, so derive height deterministically:
- If `building:levels` exists → `levels * 3.5`.
- Else if the polygon's area > 4000 m² → `18`.
- Else if area > 1500 m² → `12`.
- Else → `8`.
- Then override from an explicit table so the hero buildings read correctly:
  `{'MacLaurin Building': 20, 'Bob Wright Centre': 24, 'Engineering/Computer Science Building': 22, 'Centre for Athletics, Recreation and Special Abilities': 20, 'Mearns Centre for Learning': 22, 'Student Union Building': 16}`

- [ ] **Step 3: Compute `riseDelay`**

Campus centroid = mean of all building centers. For each building, `riseDelay` =
`distance / maxDistance`, clamped `0..1`, rounded to 3 decimals.

- [ ] **Step 4: Build the walk graph**

Snap every path vertex to 6 decimal places (~0.1 m) to merge shared nodes. Build an
undirected adjacency list with haversine edge weights. Run union-find, **keep only the
largest connected component**, and re-index nodes densely.

- [ ] **Step 5: Write the failing data test**

```ts
// tests/unit/generated-data.test.ts
import { describe, it, expect } from 'vitest'
import buildings from '../../src/data/generated/buildings.geojson'
import graph from '../../src/data/generated/walkgraph.json'

const NAMES = ['MacLaurin Building', 'Bob Wright Centre', 'Engineering/Computer Science Building']

describe('generated campus data', () => {
  it('contains every building used by the schedule', () => {
    const names = new Set(buildings.features.map((f: any) => f.properties.name))
    for (const n of NAMES) expect(names.has(n)).toBe(true)
  })

  it('gives every building a positive height and a 0..1 riseDelay', () => {
    for (const f of buildings.features as any[]) {
      expect(f.properties.height).toBeGreaterThan(0)
      expect(f.properties.riseDelay).toBeGreaterThanOrEqual(0)
      expect(f.properties.riseDelay).toBeLessThanOrEqual(1)
    }
  })

  it('produces a single fully-connected walk graph', () => {
    expect(graph.nodes.length).toBeGreaterThan(3000)
    const seen = new Set<number>([0])
    const stack = [0]
    while (stack.length) {
      const cur = stack.pop()!
      for (const [nb] of graph.adj[cur]!) if (!seen.has(nb)) { seen.add(nb); stack.push(nb) }
    }
    expect(seen.size).toBe(graph.nodes.length) // largest component only => fully connected
  })

  it('has no edge longer than 200m (would indicate a snapping bug)', () => {
    for (const list of graph.adj) for (const [, d] of list) expect(d).toBeLessThan(200)
  })
})
```
